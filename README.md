# Автоматизоване тестування SauceDemo у SideReplay

## Проєкт

Файл `Адамчук Максим.side` створено записом дій кнопкою **Record** у SideReplay 1.4.0. Після запису додано підготовку чистого кошика та перевірки результатів. Фінальну версію відкрито, виконано й збережено кнопкою **Save** у SideReplay.

Усі сценарії починаються з головної сторінки https://www.saucedemo.com/. Кожен містить власну авторизацію `standard_user` / `secret_sauce`. Після авторизації сценарій відкриває меню, виконує **Reset App State** і повторно відкриває каталог, щоб стан кошика попереднього запуску не впливав на результат.

## Результати запусків

Середовище: Windows, Google Chrome **157.0.8103.39**, SideReplay **1.4.0**, 1440 × 1000. Запуски виконано кнопкою **Run test** у SideReplay в одному тестовому профілі без зовнішнього очищення даних між фінальними запусками.

| Сценарій | Перевірка результату | Запуск 1 | Запуск 2 |
| --- | --- | --- | --- |

## Дефекти

Для `problem_user` / `secret_sauce` підтверджено два дефекти. Кожен відтворено двічі в нових сеансах і порівняно зі `standard_user`.

1. **Не працює сортування Price (low to high).** Ціни залишаються $29.99, $9.99, $15.99, $49.99, $7.99, $15.99 замість порядку зростання. [Скриншот](problem_user-sort-2.png).
2. **Sauce Labs Bolt T-Shirt не додається до кошика.** Після натискання Add to cart кошик залишається порожнім. Для standard_user товар додається. [Скриншот](problem_user-add-2.png).

Детальні баг-репорти — у вкладці [Issues](https://github.com/pamperspamp/-9/issues).

## Як відкрити і повторити

1. У Chrome відкрити SideReplay та натиснути **Open**.
2. Вибрати файл `Адамчук Максим.side`.
3. Відкрити SauceDemo у вкладці цього самого вікна Chrome.
4. Вибрати сценарій у списку та натиснути **Run test**. Повторити для кожного сценарію.

Для здачі подати файл `.side` та посилання на репозиторій.
